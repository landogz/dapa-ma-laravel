Step 1 — Prepare DNS

Create an A record (recommended before HTTPS):

YOUR_DOMAIN  →  SERVER_IP

Skip if you will use http://SERVER_IP only for now.

Step 2 — SSH into the server

ssh YOUR_USER@SERVER_IP

You need a user that can run sudo.

Step 3 — Update Ubuntu and install Git

sudo apt update
sudo apt upgrade -y
sudo apt install -y git

Step 4 — Download the installer

git clone https://github.com/landogz/dapa-ma-laravel.git /tmp/dape-ma-laravel
Always use a fresh clone so you get the latest deploy/install-ubuntu.sh.

Step 5 — Run the stack installer

Installs Nginx, PHP, MySQL, Composer, clones the app, creates DB user, Nginx site, queue worker, firewall.

Option A — Domain + your DB password

sudo \
  APP_DOMAIN=YOUR_DOMAIN \
  APP_URL=https://YOUR_DOMAIN \
  DB_DATABASE=DB_NAME \
  DB_USERNAME=DB_USER \
  DB_PASSWORD='DB_PASS' \
  bash /tmp/dape-ma-laravel/deploy/install-ubuntu.sh

Option B — IP only

sudo \
  APP_URL=http://SERVER_IP \
  DB_DATABASE=DB_NAME \
  DB_USERNAME=DB_USER \
  DB_PASSWORD='DB_PASS' \
  bash /tmp/dape-ma-laravel/deploy/install-ubuntu.sh

Option C — Auto-generate DB password

sudo bash /tmp/dape-ma-laravel/deploy/install-ubuntu.sh
sudo cat /var/www/dape-ma-laravel/.install-credentials
Wait for INSTALL COMPLETE. Log: /var/log/dape-ma-install.log

Default WEB_INSTALLER=1 skips migrate so you finish in the browser at /install/.

Step 5b — Add MySQL connection to .env

Laravel reads the database from /var/www/dape-ma-laravel/.env. The stack script and web installer usually write this for you. Use this when you need to set or fix MySQL by hand.

1) Open the file

cd /var/www/dape-ma-laravel
sudo nano .env

2) Set these MySQL lines

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=DB_NAME
DB_USERNAME=DB_USER
DB_PASSWORD=DB_PASS
  • Same server as MySQL → DB_HOST=127.0.0.1
  • Separate DB server (DDB) → use the DB private IP, not 127.0.0.1
  • If the password has @, #, spaces, or quotes, wrap it in double quotes.

3) Example (DDB split app + DB)

App: 10.0.0.10 (public 203.0.113.10) · DB: 10.0.0.20 — replace with your hosts

DB_CONNECTION=mysql
DB_HOST=10.0.0.20
DB_PORT=3306
DB_DATABASE=your_database
DB_USERNAME=your_db_user
DB_PASSWORD="YourPassword@here"

APP_URL=https://your-domain.example
DBA must allow MySQL from the app host on port 3306. Test: mysql -h 10.0.0.20 -u your_db_user -p your_database -e "SELECT 1;"

4) Before first migrate

If tables are not created yet, use file drivers so cache clear does not fail on missing cache / sessions tables. 
CACHE_STORE=file
SESSION_DRIVER=file

After a successful migrate, you can switch back to:

CACHE_STORE=database
SESSION_DRIVER=database

5) Apply and test

cd /var/www/dape-ma-laravel
CACHE_STORE=file SESSION_DRIVER=file php artisan optimize:clear
php artisan migrate --force
php artisan db:seed --force
sudo sed -i 's/^CACHE_STORE=.*/CACHE_STORE=database/' .env
sudo sed -i 's/^SESSION_DRIVER=.*/SESSION_DRIVER=database/' .env
php artisan config:cache
php artisan db:show

6) Create MySQL DB + user yourself (if needed)

sudo mysql -e "
CREATE DATABASE IF NOT EXISTS your_database CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER IF NOT EXISTS 'your_db_user'@'localhost' IDENTIFIED BY 'YourPassword@here';
ALTER USER 'your_db_user'@'localhost' IDENTIFIED BY 'YourPassword@here';
GRANT ALL PRIVILEGES ON your_database.* TO 'your_db_user'@'localhost';
FLUSH PRIVILEGES;
"

Then put the same name / user / password into .env.

Step 7 — Enable HTTPS

Option A — Network Admin SSL (port 80 blocked) — DDB

/etc/ssl/certs is usually only the system CA store. On the DDB app server, site certs were in /home/YOUR_USER/Installer/cert/your-domain.crt + .key (or a wildcard that covers YOUR_DOMAIN). 

cd /var/www/dape-ma-laravel
sudo git config --global --add safe.directory /var/www/dape-ma-laravel
sudo git pull origin main

# Auto-finds Installer/cert, copies to /etc/ssl, Nginx 443-only (no port 80)
sudo bash deploy/apply-nginx-ssl.sh

# Manual override:
sudo \
  SSL_CERTIFICATE=/home/YOUR_USER/Installer/cert/your-domain.crt \
  SSL_CERTIFICATE_KEY=/home/YOUR_USER/Installer/cert/your-domain.key \
  bash deploy/apply-nginx-ssl.sh
Script installs certs to /etc/ssl/certs/YOUR_DOMAIN.crt and /etc/ssl/private/YOUR_DOMAIN.key, then reloads Nginx.

Option B — Let’s Encrypt (needs port 80 open)

Only if Network Admin allows HTTP temporarily for the ACME challenge.

sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d YOUR_DOMAIN

cd /var/www/dape-ma-laravel
sudo sed -i 's|^APP_URL=.*|APP_URL=https://YOUR_DOMAIN|' .env
sudo -u www-data php artisan config:cache

Troubleshooting

ProblemFix
cache table missing Set CACHE_STORE=file and SESSION_DRIVER=file, then migrate / open /install/
Migration failed (web installer) See Migration failed recovery below — often stale config cache or migration order, not wrong password
Access denied for user Check DB_USERNAME / DB_PASSWORD; quote passwords with @ (DB_PASSWORD="…"); recreate MySQL user (Step 5b.6)
Connection refused to remote DB IP Use DB_HOST=127.0.0.1 if MySQL is on the app server, or ask DBA to open port 3306 from the app private IP
Artisan ignores new DB_HOST rm -f bootstrap/cache/config.php then php artisan optimize:clear
Old script in /tmp rm -rf /tmp/dape-ma-laravel then clone again
502 Bad Gateway sudo systemctl status php8.3-fpm nginx
Permission errors sudo chown -R www-data:www-data storage bootstrap/cache
Port 80 blocked / SSL already uploaded Use sudo bash deploy/apply-nginx-ssl.sh (443 only)

Migration failed recovery

On DAPEMA DEV, /install/ showed Migration failed even with correct UI credentials. Two fixes were required:

1) Stale config cache / wrong host

UI said 127.0.0.1 but cached config still targeted an unreachable remote DB host (example: 10.0.0.20). Local MySQL on the app server worked.

cd /var/www/dape-ma-laravel
mysql -h 127.0.0.1 -u your_db_user -p your_database -e "SELECT 1;"

sudo sed -i 's/^DB_HOST=.*/DB_HOST=127.0.0.1/' .env
sudo sed -i 's/^DB_PASSWORD=.*/DB_PASSWORD="YOUR_DB_PASSWORD"/' .env
sudo sed -i 's/^CACHE_STORE=.*/CACHE_STORE=file/' .env
sudo sed -i 's/^SESSION_DRIVER=.*/SESSION_DRIVER=file/' .env

sudo rm -f bootstrap/cache/config.php
sudo -u www-data php artisan optimize:clear

Use a remote DB_HOST only after mysql -h THAT_IP … -e "SELECT 1;" succeeds from the app server.

2) Migration order: daily_verses missing

Error looked like: Table 'your_database.daily_verses' doesn't exist while altering for Kid Listo fields. The alter file was dated before the create table migration.

Repo fix: rename to run after create:

  • Wrong: 2026_04_06_160000_add_kid_listo_fields_to_daily_verses.php
  • Correct: 2026_07_01_130200_add_kid_listo_fields_to_daily_verses.php
cd /var/www/dape-ma-laravel/database/migrations
sudo mv 2026_04_06_160000_add_kid_listo_fields_to_daily_verses.php \
        2026_07_01_130200_add_kid_listo_fields_to_daily_verses.php

cd /var/www/dape-ma-laravel
sudo -u www-data php artisan migrate --force
sudo -u www-data php artisan db:seed --force

sudo sed -i 's/^CACHE_STORE=.*/CACHE_STORE=database/' .env
sudo sed -i 's/^SESSION_DRIVER=.*/SESSION_DRIVER=database/' .env
sudo -u www-data php artisan config:cache

sudo bash -c 'mkdir -p storage/app; echo "{\"installed_at\":\"'"$(date -u +%Y-%m-%dT%H:%M:%SZ)"'\"}" > storage/app/installed'
sudo chown -R www-data:www-data storage bootstrap/cache

Seeded admin: superadmin@yopmail.com / password (change after first login).
