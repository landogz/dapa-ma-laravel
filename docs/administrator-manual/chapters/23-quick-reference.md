# 23. Quick reference

| I want to… | Go to |
|---|---|
| Sign in | `/admin/login` |
| Dashboard | Overview → Dashboard |
| Create a post | Content → Posts → Create Post |
| Delete a comment | Posts → View → Comments → Delete |
| Add a contest | Content → Contests → Add Contest |
| Add IEC material | Content → IEC Materials → Add IEC Material |
| Pin a rehab center | Services → Rehab Centers → Add Rehab Center |
| Edit self-care questions | Care → Care Toolkit → Add Question |
| Export care results | Care → Care Checks → Export CSV |
| Update a hotline | Care → Care Support → Add Resource / Edit |
| Review a journal entry | Care → Journal → View |
| Add a Hope partner | Hope → Hope Directory → Add Organization |
| Add a Hope event | Hope → Hope Events → Add Event |
| Send an inbox alert | Reach → Notifications → Send Notification |
| Download analytics | Reach → Analytics → Export CSV |
| Add staff | Administration → Users → Add User |
| Edit Privacy Policy | Administration → Settings → Privacy Policy |
| Change a sky color | Administration → Lookups |
| Change an app button label | Administration → App Translations |
| Block a word | Administration → Word Blocking → Add word |
| Edit my photo or password | Account menu → Edit Profile |
| Sign out | Account menu → Sign Out |

End of the DAPE-MA Administrator Manual.
