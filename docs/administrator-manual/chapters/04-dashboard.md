# 4. Dashboard

Left menu: **Overview → Dashboard** (`/admin/dashboard`).

**Figure 5.** Dashboard. 1 Search, 2 Account menu, 3 Quick Actions, 4 Count cards.

![Figure 5. Dashboard](../figures/02-dashboard.png)

## 4.1 What you see

- **Quick Actions:** New Post, Add Rehab Center, Add Contest, Add IEC Material, Add Translation, Send Notification. Each opens the same dialog as the matching menu page.
- **Count cards:** Posts, Rehab Centers, Contests, IEC Materials, App Translations, Notifications, Users, Journal. Tap a card to open that page.
- **Activity Over Time** and **Recent Activity** summarize recent app and content events.
- **Top Content** lists most-viewed posts.

## 4.2 Search everything

1. Click the search box (or press ⌘K).
2. Type at least two letters.
3. Results include pages, actions, and matching records. Use the arrow keys and Enter, or tap a result.

On a phone, tap the search icon to open the same panel.
