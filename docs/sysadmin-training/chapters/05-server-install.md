# 6. Production server and first install

## 6.1 Stack (Ubuntu 24.04)

| Piece | Notes |
|---|---|
| Nginx | Document root → `/var/www/dape-ma-laravel/public`, TLS 1.2/1.3, `client_max_body_size 14M` |
| PHP 8.3-FPM | gd, mbstring, mysql, zip, intl, opcache, bcmath |
| MySQL 8 | App database + least-privilege user |
| Composer | `--no-dev --optimize-autoloader` on production |
| Supervisor | `dape-ma-queue` → `queue:work` |
| Cron | `* * * * * php artisan schedule:run` |
| UFW | SSH + HTTPS (port 80 may be blocked by Network Admin) |

Security headers on Nginx: `X-Frame-Options SAMEORIGIN`, `X-Content-Type-Options nosniff`, `Referrer-Policy strict-origin-when-cross-origin`, `Strict-Transport-Security`.

PHP-FPM must pass `HTTP_AUTHORIZATION` so Sanctum Bearer tokens work.

## 6.2 First install (blank VPS)

Follow `deploy/INSTALL-FROM-SCRATCH.md`. Summary:

1. DNS A record → server IP.
2. SSH as a sudo user.
3. `sudo apt update && sudo apt install -y git`
4. Clone `https://github.com/landogz/dapa-ma-laravel.git`
5. `sudo bash deploy/install-ubuntu.sh` (sets Nginx, PHP, MySQL, Composer, queue, cron).
6. Open `/install/` in a browser: requirements → app URL → database → migrate/seed.
7. Sign in, change the Super Admin password, set `DAPE_SHOW_DEMO_LOGIN=false`.
8. Move `public/install` aside so the installer cannot run again:

```
sudo mv /var/www/dape-ma-laravel/public/install /var/www/dape-ma-laravel/public/install.bak
```

Installer lock file: `storage/app/installed`. Delete it only if you **intentionally** re-run `/install/`.

Credentials generated by the script (if any) live in `/var/www/dape-ma-laravel/.install-credentials`. Do not commit that file.

## 6.3 HTTPS on DDB

Port 80 is often blocked. Use the wildcard cert from the DDB installer folder, not the system CA bundle alone:

```
cd /var/www/dape-ma-laravel
sudo git config --global --add safe.directory /var/www/dape-ma-laravel
sudo bash deploy/apply-nginx-ssl.sh
```

Template: `deploy/nginx-dape-ma-ssl.conf`. Server name: `dapemade.ddb.gov.ph`.

## 6.4 Split database

If MySQL is on another host, set `DB_HOST` to that **private** IP only after `mysql -h THAT_IP …` works from the app host. If MySQL is on the app server, use `127.0.0.1`.

## 6.5 File permissions

```
sudo chown -R www-data:www-data /var/www/dape-ma-laravel
sudo find /var/www/dape-ma-laravel/storage /var/www/dape-ma-laravel/bootstrap/cache -type d -exec chmod 775 {} \;
```

Prefer committed `public/build/` assets. Do not require Node on production unless `INSTALL_NODE=1` is explicitly needed.

## 6.6 Exercise

On a **training** VM only, run the health URL and `php artisan about`. Confirm `APP_ENV` and debug are production-safe. Do not run the installer against live.
